[5. ANALISIS ESTIMASI KEBUTUHAN DAN RISIKO PENGGUNAAN MEMORI (RAM)]
  PENTING: Ukuran file di disk (3,05 GB) TIDAK SAMA dengan kebutuhan RAM saat objek dimuat!
  Faktor-faktor pelipatgandaan memori pada file Pickle:
  1. Sifat Serialisasi Pickle: Modul pickle menyimpan representasi hierarki objek Python.
     Saat proses unpickling (pickle.load), Python tidak hanya membaca byte dari disk, tetapi
     harus menginstansiasi struktur objek Python lengkap, tabel memo referensi, dan pointer memory.
  2. Overhead Objek Kolom 'signal_pleth': Kolom ini berisi array sinyal gelombang frekuensi 80 Hz.
     Jika disimpan sebagai kolom bertipe 'object' (kumpulan 961.357 array/list individual), setiap baris
     memiliki overhead PyObject (pointer, metadata tipe, dsb.) yang melipatgandakan ukuran footprint.
  3. Lonjakan Memori Puncak (Peak Memory Spike): Selama proses pickle.load(), modul pickle menahan
     buffer streaming di memori bersamaan dengan pembangunan DataFrame. Alokasi puncak biasanya
     mencapai 2,0x hingga 3,0x ukuran berkas asli di disk (estimasi 6,5 GB hingga 9,5 GB).
  4. Ruang Operasi Lanjutan (Working Buffer): Setelah DataFrame dimuat, operasi indexing, slicing,
     atau konversi tipe data membutuhkan RAM tambahan sebesar 1,0x - 1,5x ukuran DataFrame.

  Estimasi Kebutuhan RAM:
  - Ukuran file di disk            : ~3,05 GB
  - Estimasi ukuran objek di RAM   : ~4,50 - 6,00 GB
  - Estimasi lonjakan RAM puncak   : ~7,50 - 10,00 GB
