     Hasil ini tidak boleh diinterpretasikan sebagai diagnosis klinis.


2. VERIFIKASI PARAMETER PREPROCESSING AKTUAL (BARIS KODE AKTUAL)
--------------------------------------------------------------------------------
Pemeriksaan dilakukan langsung pada berkas kode produksi:
- scripts/process_uci_full.py (Pemrosesan 12.000 rekaman UCI)
- scripts/extract_osasud_features_full.py (Pemrosesan 30 pasien OSASUD)

Berikut adalah parameter aktual yang berjalan pada implementasi kode:

1. Jenis Filter:
   - Chebyshev Type II (scipy.signal.cheby2).
2. Orde Filter:
   - UCI   : N = 4 (scripts/process_uci_full.py, baris 66: CHEBY_ORDER = 4)
   - OSASUD: N = 4 (scripts/extract_osasud_features_full.py, baris 59: CHEBY_ORDER = 4)
3. Parameter Redaman Stopband (rs) [KOREKSI PENTING DARI NARASI LAPORAN]:
   - UCI   : rs = 20 dB (scripts/process_uci_full.py, baris 67: CHEBY_RS_DB = 20)
   - OSASUD: rs = 20 dB (scripts/extract_osasud_features_full.py, baris 60: CHEBY_RS_DB = 20)
   - Catatan Klarifikasi: Narasi pada laporan Tahap 9B sempat menyebut rs=40 dB atau 30-40 dB.
     Kode aktual yang benar-benar memproses data final membuktikan bahwa rs=20 dB digunakan
     secara konsisten pada kedua dataset sejak tahap pilot hingga eksekusi final.
4. Frekuensi Kritis (Wn) dan Karakteristik Respon Frekuensi scipy.signal.cheby2:
   - Parameter Kode: Wn = [0.5, 8.0] Hz
   - Sampling Rate : UCI fs = 125 Hz, OSASUD fs = 80 Hz.
   - PENEGASAN TEKNIS MATEMATIS PENTING:
     Dalam pustaka scipy.signal.cheby2, parameter Wn BUKANLAH frekuensi batas -3 dB dari passband
     (sebagaimana pada filter Butterworth). Pada Chebyshev Type II, Wn mendefinisikan frekuensi
     tepi STOPBAND (stopband edge), yaitu titik frekuensi di mana atenuasi mulai mencapai
     minimal rs (20 dB).
     Berdasarkan evaluasi numerik respon frekuensi (sosfreqz):
     * Pada UCI (fs=125 Hz)   : Batas passband riil (-3 dB) berada pada [0.625 Hz, 6.438 Hz].
     * Pada OSASUD (fs=80 Hz) : Batas passband riil (-3 dB) berada pada [0.640 Hz, 6.480 Hz].
     * Kedua filter memiliki respon passband yang flat murni (gain 0.0 dB pada ~2.0 Hz) tanpa ripple
       pada daerah lolos, sehingga mempertahankan integritas morfologi puncak sistolik dan dikrotik.
5. Implementasi Fase Nol (Zero-Phase Filtering):
   - Menggunakan Second-Order Sections (sos) dan scipy.signal.sosfiltfilt
     (UCI baris 335; OSASUD baris 473).
   - Menghasilkan phase response nol murni tanpa pergeseran waktu (zero delay).
6. Normalisasi Sinyal Z-Score:
   - TIDAK DITERAPKAN pada sinyal mentah atau terfilter sebelum ekstraksi fitur.
   - Skala unit mentah fotodetektor dipertahankan agar fitur amplitudo pulsa tidak kehilangan variasi fisiologis.
7. Skewness SQI:
   - Dihitung sebagai salah satu dari 15 prediktor model ('skewness'), BUKAN sebagai filter pembuang jendela.
8. Indeks Kekakuan Arteri (Stiffness Index / SI):
   - Tidak dihitung karena dataset sekunder tidak memiliki metadata tinggi badan subjek.
9. Empat Rasio APG (b/a, c/a, d/a, e/a):
   - Dipertahankan penuh sebagai kandidat fitur dengan kriteria representatif denyut (valid_beats >= 10, coverage >= 20%).
